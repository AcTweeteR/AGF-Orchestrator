# Contributing

Contributions should improve the clarity, completeness, or internal consistency of the AGF-Orchestrator reference model.

## Scope

This repository accepts documentation and architecture decisions. Proposals for code, CI, scripts, SDKs, APIs, automation, or provider-specific orchestration are out of scope for this documentation baseline.

## Change expectations

Explain the problem, the affected concept, and the compatibility impact. Update the canonical document for the concept and add cross-references rather than restating its definition elsewhere. Use an architecture decision record when the change alters a boundary, authority, lifecycle invariant, or interoperability rule.

## Review standard

Reviewers check formal meaning, terminology, vendor neutrality, non-duplication, and link integrity. A change is ready when its claims are testable by reading the model and its impact on adjacent documents is explicit.
