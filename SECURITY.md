# Security

AGF-Orchestrator treats security as a governance and evidence concern. This repository contains no executable system and therefore has no runtime vulnerability-reporting endpoint.

Report a security-sensitive design issue privately to the project maintainers identified by the project hosting the repository. Do not disclose exploit details publicly until maintainers have assessed the issue and coordinated a response.

Design proposals should address least privilege, separation of duties, provenance of evidence, protection of secrets, human approval boundaries, and failure containment. See [DECISION_MODEL.md](docs/DECISION_MODEL.md), [REVIEW_PIPELINE.md](docs/REVIEW_PIPELINE.md), and [HUMAN_INTERVENTION.md](docs/HUMAN_INTERVENTION.md).
