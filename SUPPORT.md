# Support

AGF-Orchestrator is pre-1.0 open source software maintained on a best-effort basis.

## Questions and usage help

Use GitHub Issues for reproducible bugs and feature requests. Before opening an issue, search existing issues and the architecture/runtime documentation.

For a bug report, include:

- AGF-Orchestrator version or commit SHA;
- operating system and Python version;
- command or workflow being run;
- expected and observed result;
- minimal reproduction where possible;
- redacted logs/evidence relevant to the failure.

Do not include credentials, private repository contents, signing keys, access tokens, cookies, or unredacted protected state.

## Security

Potential authority bypasses, provenance/evidence forgery, secret disclosure, or unauthorized external mutations must follow [SECURITY.md](SECURITY.md), not a public issue.

## Scope

The project can help diagnose AGF-Orchestrator behavior. Maintainers cannot guarantee support for third-party providers, hosted services, local model runtimes, GitHub account policy, or modified forks outside the project's documented contracts.
