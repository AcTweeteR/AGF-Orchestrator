# Roadmap

Maturity describes operational capability, not product branding. Each level retains the governance, authority, evidence, and fail-closed requirements of the previous level.

| Level | Capability | Required characteristic |
|---|---|---|
| 0 | Documentation | Shared model, roles, lifecycle, and decisions are defined |
| 1 | Manual orchestration | Humans coordinate documented stages and record evidence |
| 2 | Semi-autonomous orchestration | Bounded roles perform repeatable work with human gate control |
| 3 | Fully orchestrated workflows | Workflow transitions and evidence handling are coordinated end to end |
| 4 | Policy-driven execution | Applicable policy determines routing, controls, and gates consistently |
| 5 | Self-improving orchestration | Measured outcomes improve planning and controls without weakening governance |

Progression requires evidence that the next level preserves authority, traceability, separation of duties, human intervention boundaries, and recovery behavior. Higher autonomy never grants an agent authority to redefine AGF.
